# Dissero — manutenção do canal público

Leia o README antes de alterar este repositório. Este é o catálogo público de
distribuição, não a origem confirmada do site hospedado nem do DisseroHub local.
Não modifique arquivos gerados de `plugins/dissero/`, manifests, hooks, licenças,
OAuth ou regras de acesso para aplicar uma recomendação de desenvolvimento web.
A disponibilidade dos arquivos não concede licença.

## Orientação web consultiva

Para mudanças em páginas, consulte [Modern Web Guidance](docs/modern-web-guidance.md)
e os guias oficiais pertinentes. A meta inicial é **Baseline Widely Available**;
recursos fora dela exigem detecção de suporte e alternativa funcional. Uma
recomendação de guia não autoriza redesenho, mudança de contrato ou publicação.
Não instale ferramentas globais, não acrescente dependências de produção e não
transforme o scanner em requisito da CI por esta orientação. Preserve trabalho
local e execute as verificações existentes antes de propor uma mudança.

Nesta árvore, a referência web se limita à manutenção da documentação e ao
encaminhamento para a origem correta. Não embuta habilidades de programação web
no plugin jurídico e não altere a lista de arquivos da distribuição para isso.
